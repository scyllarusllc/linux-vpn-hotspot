Overview

One card joins the router, the other broadcasts a hotspot. Closer to the center = stronger signal, bigger circle = more traffic, moving dots = data flowing. Refreshes every 5 seconds.

Online (one color per device) Moving dots = data: outward = download, inward = upload; faster and denser = more traffic Offline (last hour) Circle size = current traffic Rings = signal strength (dBm) “4 ms” on a line = ping time (amber slow, red very slow) Count = proxy rejections (last hour) Many retries (interference) Hover anything for details

VPN / proxy Manage proxies

Hotspot clients go through this VPN or proxy automatically: nothing to install on the phone, and the phone sees no VPN. Pick another one above to switch (phones move over right away while it is on), or add, test and edit them on the Proxies page. Keys stay on the laptop. Turning it on or off needs root: a password dialog appears on the laptop.
